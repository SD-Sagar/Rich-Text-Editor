SD Word – Lightweight Vanilla JS Rich Text Editor

Description:
SD Word is a fast, lightweight, and dependency-free rich text editor built using pure JavaScript.

Features:
- MS Word style formatting toolbar
- Export as PDF, Text, and HTML
- Auto-save using localStorage
- Word & character counter
- Copy to clipboard
- Print support
- Code view toggle

Installation:
1. Download the files
2. Open index.html in browser
3. Integrate into your project as needed

Usage:
You can embed the editor inside any web project by including the HTML, CSS, and JS files.

Requirements:
- Modern web browser
